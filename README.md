# BiciRuta – Web de la tienda

Web de la tienda online de BiciRuta S.L., una tienda de bicicletas de Madrid. En este proyecto se reorganiza la página original separando HTML, CSS y JavaScript, se corrigen sus errores y se lleva el control de versiones con Git y GitHub.

## Estructura

```
biciruta-web/
├── index.html          # estructura y contenido
├── css/estilos.css     # estilos
├── js/app.js           # comportamiento
├── img/logo_biciruta.png
├── README.md
└── .gitignore
```

## Cómo verlo

1. Abrir la carpeta `biciruta-web` en Visual Studio Code.
2. Tener instalada la extensión **Live Server**.
3. Abrir `index.html` y pulsar **Go Live** en la barra inferior.
4. La web se abre en el navegador en `http://127.0.0.1:5500`.
